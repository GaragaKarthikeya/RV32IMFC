RV32IMFC RISC-V CPU Implementation

A RISC-V CPU implementation supporting the RV32I base instruction set with focus on fundamental operations.

Detailed CPU Capabilities

Fully Implemented Features ✅

  • Arithmetic Operations: add, addi, register-to-register, immediate operations
  • Memory Operations: sw, word-aligned, up to ~24 bytes confirmed
  • Register Operations: 32 registers, x0 hardwired to zero, updates working
  • Control Flow: PC increment, sequential execution
  • Instruction Fetch: loading, decoding

Limitations and Untested Features ⚠️

  • Branch/jump instructions not fully tested
  • lw not extensively tested
  • Large programs may need more simulation time
  • M, F, C extensions not implemented
  • CSR, exceptions, and env calls not implemented

Installation & Setup

Prerequisites

# Ubuntu/Debian
sudo apt install iverilog gcc-riscv64-unknown-elf gtkwave

# Fedora
sudo dnf install iverilog riscv64-unknown-elf-gcc gtkwave

# macOS
brew install icarus-verilog riscv-gnu-toolchain gtkwave

Usage

Running the Simulation

./tools/compile.sh

Viewing Waveforms

gtkwave build/waveform.vcd

Creating and Running Custom Code

Step 1: Write your RISC-V Assembly Program

.section .text
.globl _start

_start:
    addi x1, x0, 10
    addi x2, x0, 5
    add x3, x1, x2
    sw x3, 0(x0)

loop:
    j loop

Step 2: Compile Assembly to Hex Format

riscv32-unknown-elf-gcc -march=rv32i -mabi=ilp32 -nostdlib -nostartfiles \
  -T tools/link.ld tests/asm/example.S -o tests/asm/example.elf

riscv32-unknown-elf-objcopy -O binary tests/asm/example.elf tests/asm/example.bin

hexdump -v -e '1/4 "%08x\n"' tests/asm/example.bin > tests/hex/example.hex

Step 3: Set as Current Test Program

ln -sf tests/hex/example.hex test.hex

Step 4: Run the Simulation

./tools/compile.sh

Troubleshooting

  • "Not enough words" warning: Normal for small programs
  • Premature simulation end: Increase delay in tb_riscv_cpu.v
  • Incorrect memory: Check addressing and word-alignment
  • Compile errors: Check Verilog syntax and file paths
